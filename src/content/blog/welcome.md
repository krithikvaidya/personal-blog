This is a sample post. Replace it with your first piece of writing, or use it as a template.

## Make it yours

Update your name and site description in `src/config.ts`, then edit the homepage in `src/pages/index.astro`.

## Write a new post

Add a Markdown file to `src/content/blog/` with a title, description, and publication date:

```yaml
---
title: 'Your post title'
description: 'A short summary of your post.'
pubDate: 2026-10-30
draft: false
---
```

Write the rest of the post below the frontmatter. Astro will add it to the writing page automatically.

Set `draft: true` while a post is in progress. Drafts are excluded from the homepage, writing page, and generated post routes.

Markdown supports **bold text**, *italics*, lists, code blocks, and [links](https://docs.astro.build/).
